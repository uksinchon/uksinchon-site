# 글 목록 삭제·휴지통·복구

기준일: **2026-11-06 (한국시간)**. 관련 범위: R02의 원고·이력 보존, R06의 직원 운영과 공개 관리. 브랜드: 영국유학센터 신촌점.

## 사용하는 방법

관리자로 `/admin/`에 로그인하면 ‘전체 직원의 글’ 목록의 각 글에 **삭제** 버튼이 보인다. 글 제목과 공개 중인 경우의 처리 내용을 확인한 뒤 삭제한다. 일반 직원 계정에는 삭제·복구 권한을 제공하지 않는다.

- 삭제하면 일반 글 목록에서 빠지고 **휴지통**으로 이동한다. 공개 글과 해당 글의 공개 사진, 블로그 목록·관련 글·사이트맵·RSS에서도 제외한다. 기존 공개 글 주소는 404다. 외부 검색 결과나 이미 복제된 자료의 즉시 삭제를 의미하지 않는다.
- 목록 상단의 **휴지통**, 또는 상태 필터의 휴지통으로 삭제한 글을 찾는다. 제목 검색과 페이지 이동도 사용할 수 있다.
- **복구**하면 원래 주소와 원고·사진을 가진 **비공개 초안**으로 돌아온다. 자동으로 다시 공개하지 않는다. 필요한 현재 버전 검토와 별도의 공개 승인을 거쳐 게시한다.
- 네이버에서 가져온 글도 같은 방식으로 삭제한다. 네이버 원문은 삭제하지 않으며 연결 이력은 남는다. 휴지통에 있는 글은 원문 목록에 상태를 표시하고 재편집·완료 원고 재적용으로 되살릴 수 없게 한다. 먼저 글 목록에서 복구해야 한다.

확인 창에서 취소하면 서버에 삭제 요청을 보내지 않는다. 통신 실패·버전 충돌은 실패로 표시하고 목록에서 성공한 것처럼 지우지 않는다. 마지막 페이지의 마지막 글을 삭제하면 이전 페이지로 돌아간다.

## 저장과 권한

기존 `cms_posts.status` 제약과 기존 게시글·미디어·버전 테이블을 바꾸지 않는다. 새 `cms_post_trash` 테이블에 글 ID, 삭제한 관리자, 실제 삭제 시각, 삭제 직전 공개 revision 참조만 기록한다. 초기 설정에 포함하며, 이미 초기 설정한 DB에는 인증된 글 API·네이버 관리 요청에서 `CREATE TABLE IF NOT EXISTS`로 추가한다. 원격 DB의 기존 데이터 변환이나 일괄 삭제 작업은 없다.

`POST /api/cms/posts/{id}/trash`, `POST /api/cms/posts/{id}/restore`는 관리자 세션·같은 Origin·현재 revision을 요구한다. 복구 역시 관리자만 할 수 있다. 삭제한 원고의 읽기·편집·검토·발행·사진 업로드 API는 410으로 막는다. 익명에게는 휴지통·비공개 원고를 노출하지 않는다.

삭제와 복구는 각각 새 revision을 만들고 이전 버전은 그대로 남긴다. 현재 snapshot에서 과거의 공개 승인 메타를 제거하여 새 버전의 검토로 오해하지 않도록 한다. 저장 토큰과 revision 조건을 갖춘 D1 batch 안에서 원고 상태 변경, 휴지통 기록, 새 버전, 공개 사진 권한 회수, 작업 이력을 함께 처리한다. 동시 저장·발행·네이버 재편집이 삭제를 덮어쓰지 않도록 검증한다.

복구 시 최초 발행일·slug는 유지한다. 단순 삭제·복구가 실질적인 내용 수정일을 만들지 않는다. 예전 사실 확인이나 AI 검토를 새 revision의 승인으로 복사하지 않는다. 사진 바이트와 모든 과거 버전은 보존하며, 보관 기간에 따른 자동 영구 삭제나 물리 삭제 UI는 추가하지 않는다.

## 배포와 복구 제약

서버·데이터 보호, 관리자 UI, 운영 문서를 별도 논리 단위로 커밋한다. 배포 성공은 해당 커밋의 Cloudflare Pages 체크로 확인한다. 기능 구현 중 실제 운영 글을 삭제하는 작업은 포함하지 않는다.

운영자가 삭제한 글의 일반적인 복구는 휴지통의 ‘복구’로 처리한다. 전체 D1 백업·복원이나 저장소 밖 사진·외부 캐시 복구를 대신하는 기능은 아니다. 원격 DB 백업·복원은 이번 환경에서 실행하지 않았다.

아직 기능을 쓰지 않았다면 이전 코드로 되돌릴 수 있다. 휴지통 기록이 생긴 뒤에는 해당 기록을 이해하는 필터·차단을 유지해야 한다. 이를 무시하는 옛 코드로 회귀하면 삭제한 글이 일반 목록의 초안으로 다시 나타날 수 있다. 공개 revision은 비워 둔 상태이므로 자동으로 공개되지는 않는다. 휴지통 테이블·사진·버전 이력을 지우는 롤백은 사용하지 않는다.
