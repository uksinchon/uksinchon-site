# Meta 픽셀과 리타겟팅

## 현재 동작

2026년 10월 30일 운영자 요청에 따라 방문정보 사용 안내창, 허용·거부 버튼, 광고 쿠키 설정 버튼과 선택값 저장 기능을 제거했다. 홈페이지·약대 상담·2027 입학 설명회 페이지에서 별도 허용 조작 없이 픽셀 **1634770791440664**의 `PageView`를 자동 실행한다. 기존 브라우저에 남은 선택 기록은 읽거나 변경하지 않는다. 방문자가 동의했다는 기록이나 `consent/grant` 호출을 생성하지 않는다.

광고 방문 이벤트는 Meta에 페이지 URL·브라우저·기기·IP·광고용 식별자 등이 전달될 수 있는 기능이다. 상담 양식의 이름·학력·영어 수준·문의 내용은 자체 연동 코드에서 읽거나 보내지 않는다. `Lead` 이벤트와 문의 완료 추적은 연결하지 않았다. 카카오톡 클릭·메시지 작성만으로 접수가 완료되었다고 기록하지 않는다.

## 설정과 확인

설정 파일은 `assets/meta-pixel-config.js`다. 중지하려면 `enabled: false`로 변경하고 배포한다.

```js
window.UK_META_PIXEL_CONFIG = Object.freeze({
  enabled: true,
  pixelId: '1634770791440664'
});
```

로드·초기화는 `assets/meta-pixel.js`에서 처리한다. 운영 도메인 `uksinchon.com`, `www.uksinchon.com`의 HTTPS와 로컬 개발 주소에서만 작동한다. PC 파일 미리보기와 다른 도메인에서는 실행하지 않는다. 예상하지 못한 경로·쿼리·해시가 있는 URL에서는 실행을 생략한다. 광고 캠페인 태그와 클릭 식별자는 제한된 문자 형식만 허용한다. 페이지당 라이브러리 1회, 초기화 1회, `PageView` 1회로 제한하며 JavaScript가 꺼진 경우 추적 이미지를 추가하지 않는다.

자동 이벤트 수집을 줄이기 위해 `fbq('set', 'autoConfig', 'false', PIXEL_ID)`를 `init` 앞에 호출하며 이름·이메일·전화번호 등 매칭용 사용자 객체를 제공하지 않는다. Meta 계정의 자동 고급 매칭·자동 이벤트 설정은 직접 확인하지 못했으며 코드 검증과 구분한다. 기존 Cloudflare Web Analytics 설정은 변경하지 않았다.

별도 안내창과 설정 버튼은 없다. `assets/meta-pixel.css`는 제거했으며 브라우저 저장소 접근이 없어도 작동한다. 단독 HTML 미리보기에는 픽셀을 넣지 않는다.

## 실제 이벤트 수신 확인

1. [Meta 이벤트 관리자](https://business.facebook.com/events_manager2/)에서 픽셀/데이터세트 **1634770791440664**를 선택한다.
2. 테스트 이벤트 화면을 열고 일반 브라우저에서 공개 홈페이지 또는 `/pharmacy/`, `/seminar-2027/`을 방문한다. 별도 허용 버튼을 누를 필요가 없다.
3. 올바른 ID에 `PageView`가 들어오는지 확인한다. Meta Pixel Helper도 사용할 수 있다. 브라우저 차단 기능 등으로 모든 방문이 기록되는 것은 아니다.
4. 방문 이벤트가 쌓이면 광고 관리자에서 전체 방문자 또는 `/pharmacy/` 등 URL별 웹사이트 맞춤 타겟을 만든다. 설치 전 방문자를 소급해서 만들지는 못한다.

## 검증

`python3 scripts/check_meta_pixel.py`의 브라우저 검증 12개가 통과했다. Meta 라이브러리를 대역으로 처리하며 실제 Meta 계정으로 이벤트를 보내지 않는다. 현재 자동 로딩·허용 UI 없음·단일 PageView·잘못된 ID와 비활성 설정·세 페이지 경로·상담 입력 제외·미확인 URL 차단·정상 광고 태그·저장소 차단·기존 선택 기록 미변경·다운로드 후 URL 재확인·라이브러리 차단·JavaScript 비사용을 검증한다.

이전 작업에서는 실제 SDK가 이 Headless 브라우저를 Meta BotBlocking 규칙으로 차단하는 것을 확인했다. 탐지 기능을 우회하지 않았다. 현재 변경 검증도 실제 계정의 수신 확인을 대신하지 않는다. 배포 성공과 Meta 이벤트 관리자 수신 여부는 별도로 확인한다.
