# 홈에서 사전 진단·지점 문의로 연결

확인일: **2026-11-19 한국시간**. 관련 로드맵 **R07(홈), R03(사용자 입력 동선), R06(검증·배포)**. 기준 코드 `b928fd1`.

사용자가 ‘내 조건으로 상담하기’를 흥미·동기를 유발하는 문구로 바꾸고, 어학연수는 Hello UK, 정규유학은 Study Path에서 상황을 진단한 뒤 문의하는 흐름을 요청했다.

## 현황과 판단

- `hello-uk/index.html`: 이미 연수 상황·기간·목적·영어·지역·연락 선호 질문과 결과 보딩패스·복사·공유 기능이 있다.
- `study-path/index.html`: 이미 학부·파운데이션·편입, 석사·프리마스터, 박사, 조기유학, 미정 등의 분기 질문과 결과 프로필·복사·공유 기능이 있다.
- 두 도구 모두 실제 원격 문의 전송은 기존 Formspree를 사용한다. 연락처를 입력할 경우 기존 동의·형식 검사가 적용된다. 기존 결과 안내는 ‘대화 중이던 카카오톡 방’을 전제로 하므로 홈에서 처음 방문한 고객에게는 채널 문의 연결이 더 필요하다.
- `index.html`의 기존 주 버튼은 바로 `/counsel/`로 이동했다. 진단 도구를 새로 개발하는 대신 기존 두 도구를 노출하고 결과 문의를 보강하는 안을 선택했다.

## 구현한 동선

1. 첫 화면 버튼: **“나에게 맞는 영국 유학, 먼저 알아보기”**. 보조 문구는 **“간단한 질문으로 내 상황 정리부터, 신촌점 문의까지.”**
2. 버튼과 모바일 하단 ‘나의 유학 진단’ → `/#diagnosis`의 두 선택 카드. 페이지 안의 실제 앵커·링크로 구현해 별도의 팝업·초기 개인정보 입력 없이 작동한다.
3. 어학연수 **Hello UK** → `/hello-uk/`, 대학·파운데이션·석사 등 정규유학 **Study Path** → `/study-path/`.
4. 각 도구의 결과 화면 → **1. 진단 결과 복사하기 → 2. 신촌점 카카오톡으로 문의하기**. 처음 문의하는 고객도 결과를 복사해 채널에 붙여넣을 수 있다. 방문·전화 상담 신청(`/counsel/`)과 다른 과정 선택으로 돌아가는 링크도 제공한다.

기존 사진·크림색·테라코타·녹색을 사용해 홈 디자인을 유지한다. 모바일 390×844에서는 두 카드가 고정 하단 버튼 위에 모두 들어오도록 크기와 앵커 이동 여백을 조정했다. PC에서도 지정 메인 문구와 주 버튼은 기존 첫 화면 안에 보인다. 상단의 직접 상담 예약과 카카오톡 문의는 계속 사용할 수 있다.

## 구조·데이터·검색 정책

- `index.html`, `assets/home.css`: 기존 큰 과정 바로가기 줄을 두 가지 진단 선택 영역으로 변경한다. 실제 링크이므로 홈 선택은 JavaScript 없이도 작동한다.
- `hello-uk/index.html`, `study-path/index.html`: 기존 질문·응답·결과·개인정보 동의·Formspree 전송·카카오톡 SDK는 유지하고, 결과 화면 끝에 공통 문의 선택을 추가한다. JavaScript 비활성 시에는 설명과 직접 상담 링크를 제공한다.
- `assets/diagnosis-inquiry.css`: 두 결과 화면의 공통 문의 스타일. 새로운 입력 필드·외부 요청·추적 코드를 추가하지 않는다.
- 문의 버튼은 기존 `https://pf.kakao.com/_VNmTxd`를 새 탭으로 연다. 결과·이름·연락처를 URL이나 분석 이벤트로 보내지 않는다. 추가한 버튼은 고객이 직접 복사하고 채널에서 전송하는 흐름이며, 단순 채널 열기를 실제 문의 접수 완료로 표시하지 않는다.
- ‘진단’은 기존 선택 질문으로 자기 상황과 준비 경로를 정리하는 도구다. 자동 합격 판정·학교 적합도 점수·AI 추천 기능을 새로 구현한 것으로 표현하지 않는다.
- 두 도구의 `noindex,nofollow`를 유지한다. URL·게시글 식별자·slug·공개본·CMS·DB·이미지 모델은 바꾸지 않는다. DB 변환이나 리디렉션은 필요하지 않다.
- Meta의 공개 해시 허용 목록에 `#diagnosis`만 추가한다. 진단 페이지에는 새 Pixel이나 진단 답변 이벤트를 넣지 않는다.
- `scripts/package_site.py`의 공개 목록에 기존 두 도구의 HTML·OG 이미지와 공통 CSS를 포함한다. 테스트 정적 라우터도 같은 공개 경로를 제공한다. 기존 미추적 콘텐츠 전략 폴더와 비공개 가격 자료는 작업·커밋 대상이 아니다.
