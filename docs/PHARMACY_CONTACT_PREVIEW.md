# 약대 상담 첫 화면 디자인 제안

기준일: 2026-11-03 · 브랜드: 영국유학센터 신촌점

- 제안 시안: `https://uksinchon.com/preview/pharmacy/`
- 현재 공개 페이지: `https://uksinchon.com/pharmacy/`
- 시안 파일: `preview/pharmacy/index.html`, `styles.css`, `contact.js`

PC 첫 화면에서 핵심 설명과 문의 동작을 함께 볼 수 있도록 제안했다. 기존 공개 약대 페이지를 교체한 것은 아니다. 시안은 noindex로 검색 제외를 요청하며 주소를 아는 사람은 열 수 있다.

## 배치

왼쪽에는 짧은 제목·소개와 실제 상담에서 확인할 세 가지를 둔다. 입학·진학·약사 자격의 차이는 펼쳐 읽는 안내로 제공한다. 학교·학비·진학 보장을 새로 만들지 않았다.

오른쪽에는 **카카오톡으로 바로 문의하기**를 가장 먼저 둔다. 입력 없이 기존 신촌점 채널을 열 수 있다. 그 아래에서는 현재 학력·희망 입학 시기·궁금한 점만 정리한다. 학력과 시기는 미정으로 시작할 수 있다.

상담 내용을 만들면 같은 카드가 내용 확인·복사·카카오톡 이동 화면으로 전환된다. 아래에 새 결과를 덧붙여 문서 스크롤을 만들지 않는다. 복사할 내용은 직접 수정할 수 있고 원래 조건으로 돌아갈 수도 있다.

## 실제 문의 경로

- 카카오톡: 기존 `https://pf.kakao.com/_VNmTxd`
- 전화: `02-393-1030`
- 작성 내용은 브라우저에서만 정리하며 별도 저장·문의 DB·발송 서버로 보내지 않는다.
- ‘상담 내용 만들기’나 복사만으로 접수가 완료되지 않는다. 방문자가 카카오톡 채널에 직접 붙여넣고 전송해야 한다.
- 자동 복사가 막히면 내용 선택·수동 복사를 안내한다. JavaScript를 사용할 수 없어도 전화·카카오톡은 이용할 수 있다.
- 기존 형식에 맞는 UTM 4종만 상담 메시지에 넣는다. 임의 개인정보 쿼리나 fbclid를 복사하지 않는다.
- 새 문의 접수 API·자동 전송·Lead 이벤트·미확인 프로모션은 추가하지 않았다. 시안에는 Meta 픽셀 로더가 없으며 호스팅의 기존 분석 설정은 별도다.

## PC 화면과 작은 화면

1280×650, 1280×720, 1366×650, 1366×768, 1440×900, 1920×1080의 실제 브라우저 콘텐츠 영역에서 첫 입력 화면과 결과 화면 모두 세로 문서 스크롤 없이 표시됨을 확인했다. 특히 1366×768 화면에서 제목·카카오톡·전화·입력란·내용 생성 버튼이 함께 보인다.

이것은 해당 해상도·기본 글자 크기의 확인 결과다. 브라우저 확대, 큰 글꼴, 상세 안내 펼침, 입력란 크기 변경, 더 작은 화면에서는 자연스럽게 세로 스크롤을 허용한다. 높이를 고정하거나 내용을 잘라서 화면에 강제로 맞추지 않는다. 모바일에서는 한 열로 바꾸어 세로로 읽는다.

## 검증

격리된 Chromium 검증 6개가 통과했다. PC 입력·결과 화면의 실제 문서 높이, 캠페인·선택값과 상담 메시지 일치, 직접 수정·복사·복사 차단·빈 내용 처리·조건 유지, 320~899px 가로 넘침 방지, 채널·전화 목적지, 외부 스크립트·POST·브라우저 저장 없음, JavaScript 비사용 시 기본 GET 제출 방지를 확인했다. 검증 중 실제 상담을 전송하지 않았다. 실제 카카오톡 계정 수신은 별도다.

패키지 생성기는 새 시안 파일을 공개 정적 파일 목록에 포함한다. 현재 약대 페이지는 그대로 유지하며, 운영 페이지로 선택되면 기존 픽셀·공유 메타·광고 URL·상세 안내·PC 파일 상대 경로를 유지하는 별도 반영 작업을 한다.
