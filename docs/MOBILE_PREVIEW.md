# 모바일 구성 미리보기

- 주소: https://uksinchon.com/preview/
- 파일: `preview/index.html`
- 배포: 기존 GitHub main → Cloudflare Pages 자동 배포

2026-11-02 사용자의 모바일 미리보기 요청으로 만든 구성 시안이다. 기존 홈페이지를 바꾸지 않으며 홈에서 공개 메뉴로 연결하지 않는다. `noindex,nofollow` 메타 태그로 검색 제외를 요청하지만, 주소를 아는 사람은 열 수 있는 공개 페이지다.

프롤로그 홈·매일 운영·4주 실행 탭, 카테고리별 안내 예시와 편집 메모를 제공한다. 메모는 페이지에서 저장하거나 발송하지 않는다. 픽셀 로더를 포함하지 않으며 호스팅의 기존 분석 설정은 별도다. 기존 비공개 업무 자료와 전체 기획 문서를 공개하지 않는다.

원본 계획은 로컬의 `docs/content-strategy/`에 있다. 공개 시안 수정은 `preview/index.html`에서 하며 `scripts/package_site.py`의 공개 배포 패키지에도 포함한다. 시안 사용이 끝나면 해당 페이지와 패키지 목록을 함께 정리한다.
