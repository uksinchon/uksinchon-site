# 약대 파운데이션 광고 랜딩페이지 운영 안내

공식 표기는 **영국유학센터 신촌점**이다. 제목·본문·공유 문구·상담 메시지에 같은 명칭을 사용한다.

## 페이지와 광고 연결

- 배포 후 페이지 주소: `https://uksinchon.com/pharmacy/`
- 스터디그룹에 전달할 광고용 주소 예시:
  `https://uksinchon.com/pharmacy/?utm_source=studygroup&utm_medium=paid_social&utm_campaign=pharmacy_foundation&utm_content=showreel`
- 위 주소는 기존 사이트 운영 도메인과 새 파일 경로를 기준으로 정한 **배포 예정 주소**다. 파일 수정만으로 게시되지 않는다. 실제 배포 후 공개 주소 응답과 카카오톡 채널을 운영자가 확인한 다음 광고에 사용한다.
- 스터디그룹 광고가 승인되거나 실제 집행됐다는 의미는 아니다. 광고 집행·쇼릴 검토는 스터디그룹과 별도로 진행한다.

## 문의를 받는 방식

1. 학생이 현재 학력·희망 입학 시기를 선택하고, 필요한 경우 호칭·영어 준비·궁금한 점을 입력한다.
2. ‘상담 내용 만들기’로 메시지를 생성한다. 이 단계는 접수가 아니다.
3. 학생이 메시지를 확인·수정하고 ‘내용 복사하기’를 누른다.
4. ‘카카오톡 열기’로 기존 신촌점 채널을 열어 붙여넣고 **직접 전송**한다. 신촌점이 이 채널에서 문의를 받는다.
5. 전화 문의는 `02-393-1030`으로 연결한다.

연결 채널은 기존 홈페이지에 등록된 `https://pf.kakao.com/_VNmTxd`다. 현재 환경에서 외부 채널 로그인·실제 메시지 수신까지 검증한 것은 아니다. 운영자가 광고 전에 모바일에서 실제 채널과 수신 계정을 확인해야 한다.

자동 복사가 차단되면 내용 선택과 수동 복사 안내를 제공한다. JavaScript를 사용할 수 없어도 카카오톡·전화 링크는 사용할 수 있다. 접수 성공을 가장하거나 카카오톡에 메시지가 자동 입력·전송된다고 안내하지 않는다.

사이트에 별도 문의 저장 서버·DB·메일 발송·CRM·자동 알림·광고 픽셀은 연결하지 않았다. **학생 작성만으로 연락처가 수집되거나 상담 예약이 완료되지 않는다.** 웹에서 바로 접수·저장하는 기능이 필요하면 수신 계정/서버와 개인정보 처리·보관 정책을 별도로 정한 뒤 연결해야 한다.

## 광고 유입 확인

메시지 생성 시 URL의 `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`만 검토된 문자 형식(영문·숫자·밑줄·하이픈, 각80자 이내)으로 가져온다. 학생이 실제 메시지를 전송하면 신촌점이 해당 태그를 확인할 수 있다.

분석 도구나 클릭 추적은 없으며, 전체 광고 방문 수·전환율을 자동 집계하지 않는다. 임의 쿼리·개인정보·`fbclid`는 복사하지 않는다. 작성 내용·유입 태그를 쿠키, localStorage, sessionStorage에 저장하지 않는다.

## 내용 수정과 한계

- 페이지 본문·FAQ·연락처: `pharmacy/index.html`
- 디자인·모바일 화면: `pharmacy/styles.css`
- 메시지 생성·복사·UTM 처리: `pharmacy/consultation.js`
- 기존 홈의 명칭과 전용 페이지 링크: `index.html`

학교·캠퍼스·입학 연도별 공식 자료가 제공되지 않아 대학명·정확한 입학 기준·학비·진학 보장·약사 자격 보장을 기재하지 않았다. 상담 시 학교의 최신 공식 자료로 확인한다. 특정 대학이나 스터디그룹의 공식 제휴·검수 완료를 주장하지 않는다.

쇼릴 영상 파일/공개 주소는 현재 제공되지 않았다. 페이지에 가짜 재생 버튼이나 임의 영상을 넣지 않았다. 영상이 제공되면 검토된 파일·자막·사용 권한을 확인해 추가할 수 있으며, 광고 영상이 페이지에 반드시 포함되어야 하는 것은 아니다.

## 로컬 확인

PC에서 ZIP을 **모두 압축 해제**한 뒤 `index.html`을 더블클릭하면 홈과 약대 페이지를 볼 수 있다. 링크는 `./pharmacy/index.html`처럼 상대 파일 경로이며, 약대 페이지의 CSS·JS·로고도 상대 경로로 연결한다. `D:/pharmacy/` 같은 드라이브 최상위 경로로 이동하지 않는다. 일반 홈페이지 파일을 사용할 때는 폴더 구조를 유지한다.

가장 간단한 미리보기는 함께 제공하는 **`약대_상담페이지_바로열기.html`**을 더블클릭하는 것이다. CSS·JavaScript·로고를 포함한 단독 파일이므로 다른 파일 설치나 서버 실행이 필요 없다. 실제 문의는 내용을 복사해 카카오톡으로 직접 전송하며, 자동 복사가 차단되면 선택된 내용을 수동 복사한다. 단독 미리보기의 홈 링크는 인터넷의 `https://uksinchon.com/`으로 연결된다.

배포용 ZIP과 단독 미리보기는 `python3 scripts/package_site.py --output /workspace`로 동일한 원본에서 다시 생성할 수 있다. 가격 관리 도구·업무 DB·개인정보는 패키지 대상에 포함하지 않는다. 생성된 미리보기만으로 사이트가 공개되지는 않는다.

프로젝트 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행한다. 내부 검증 경로는 `/`, `/pharmacy/`, `/pharmacy/styles.css`, `/pharmacy/consultation.js`다. HTML/CSS/JS 정적 사이트이므로 패키지 설치나 빌드는 필요하지 않다.

검증 시 데스크톱·모바일, 필수 입력, 작성·수정·복사, 복사 거부 시 안내, JavaScript 미사용 시 연락처, 광고 태그, 키보드 이동, 실제 채널 주소와 전화 링크를 확인한다. 외부 문의를 자동 전송하지 않는다. 원본 자료와 기존 `price_manager/`의 업무 DB는 이 페이지에서 읽거나 변경하지 않는다.

## 2026년 10월 29일 검증 결과

실제 Chromium 브라우저에서 13개 기능 검증이 통과했다. 데스크톱·모바일, 320/375/390/768/1024/1440px 가로 넘침, 필수 항목 누락, 생성 결과와 입력 일치, 사용자 수정 후 정확한 복사, 빈 메시지 차단, 복사 권한 거부 시 수동 복사, 광고 태그 4종과 임의 개인정보 쿼리 제외, HTML 입력 실행 방지, 키보드와 입력 레이블, JavaScript 미사용 시 기본 GET 전송 차단 및 연락 경로, 홈에서 전용 페이지 연결을 확인했다. 사이트의 입력 정보 저장이나 외부 메시지 전송은 없었다.

로컬 HTTP로 홈·전용 페이지·CSS·JS·로고의 5개 응답이 실제 파일과 일치함을 확인했다. JavaScript 구문 검사와 변경 파일의 공백 검사도 통과했다. 공개 도메인 요청은 현재 클라우드에서 HTTP 403 응답을 받아 공개 사이트의 상태·배포 여부는 검증하지 못했다. 카카오톡 실제 상담 전송·수신은 운영자 확인이 필요하다.

### PC 파일 열기 경로 수정

배포 전용 루트 경로(`/logo.png`, `/pharmacy/` 등)가 Windows 파일 열기에서 드라이브 최상위로 해석되는 문제를 수정했다. 홈→약대는 명시적인 상대 `index.html` 파일로, 이미지·CSS·JS·홈 복귀도 상대 파일 경로로 연결한다. 같은 원본으로 단독 HTML을 생성할 때는 CSS·로고를 포함하고 JavaScript는 폼이 존재한 뒤 실행하도록 본문 끝에 넣는다.

추가 검증 7개가 통과했다. 압축을 푼 모든 로컬 링크의 파일 존재 및 폴더 범위, 단독 파일의 외부 파일 의존성 없음, 한글·공백 포함 하위 폴더에서 홈↔약대 이동과 로고·스타일·상담 생성·수정·복사, 웹 폴더/명시 파일 주소 양쪽, 다른 파일 없는 위치의 단독 HTML 기능, 모바일·카카오톡 목적지, 네트워크 없는 인라인 미리보기와 수동 복사 안내를 확인했다. 클라우드 Chromium 정책이 `file://` 직접 탐색을 차단하므로 해당 정책은 변경하지 않았으며, 실제 Windows PC에서 더블클릭한 결과까지 검증했다고 주장하지 않는다. 파일 URL의 실제 연결 대상을 검사하고, 브라우저의 하위 경로 HTTP 및 네트워크 없는 단독 콘텐츠로 기능을 검증했다.
