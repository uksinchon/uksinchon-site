## 옮긴 범위

첫 홍보 PNG, 본문 GIF 6개, 상단 배경 사진을 내려받아 로컬 이미지로 제공한다. 이미지의 원본 바이트와 애니메이션을 유지했다. `seminar-2027/source.json`에 각 이미지의 출처·크기·SHA256과 원문 본문 해시를 남겼다. 원문 전체 HTML, 인증 폼의 세션·CSRF 토큰 등은 공개 파일에 넣지 않았다.

신촌점 사이트의 공통 머리말·바닥글과 모바일 메뉴를 사용했다. HTML의 지점 명칭·카카오톡 링크 설명은 **영국유학센터 신촌점**으로 표기했다. 원문의 연사 직함 ‘이정민 지사장’과 원본 이미지 안에 있는 채널 표기는 유지했다. 이는 외부 카카오톡 채널 자체의 이름을 변경한 작업이 아니다.

원문에 게재된 통계·학교·비자 관련 문구는 원문 안내의 재현이며, 이 작업에서 각각의 별도 공식 자료까지 다시 검증했다고 보고하지 않는다. 원문 링크를 페이지 하단에 제공한다.

## 신청 흐름

‘공식 신청서 열기’는 원문 공지의 **`#seminar`** 위치를 새 창에서 연다. 원문은 `/application-seminar/form/219/`의 해당 설명회 신청서를 불러오고, 영국유학센터 서버에서 이메일·성명·휴대폰과 인증을 처리한다. 이 기존 신청 경로를 유지한다.

신촌점 정적 사이트가 본사 인증 토큰을 복제하거나 개인 정보를 별도 서버로 전송하지 않는다. 새 페이지에 입력만 하고 본사 접수가 완료됐다고 표시하지도 않는다. 실제 접수·수신은 공식 신청 시스템에서 이루어진다. 검증 시 실제 신청이나 인증 요청을 보내지 않는다.
