# 실사 이미지 중심의 따뜻한 메인 화면

확인일: **2026-11-19 한국시간**. 관련 로드맵 **R07(홈 화면), R06(검증·배포)**. 기준 코드 `5892e6e`.

사용자가 텍스트 위주의 화면을 실제 사진이 포함된 따뜻한 느낌으로 변경해 달라고 요청했다. 기존에 선택한 상담팀·사례·UK 노트 구성과 메인 문구 **“영국 유학, 어학연수 내 조건에서 출발하세요.”**를 유지하며 화면을 변경한다.

## 변경과 선택 근거

색상만 바꾸는 최소안은 첫 화면의 텍스트·상자 위주 인상을 해소하기 어렵다. 따라서 기존 첫 화면의 큰 과정 선택 상자를 **런던 실사 사진**으로 바꾸고, 과정 선택은 사진 아래의 간결한 바로가기로 옮겼다. 과정 안내 3개에도 건축물·도서관·런던 풍경 사진을 넣었다.

크림색 바탕, 테라코타 강조색, 짙은 녹색 글자·버튼, 둥근 사진 프레임으로 따뜻한 분위기를 만든다. 상담팀의 실제 프로필·사무실 사진을 유지해 지점 소개와 연결한다. 일반 풍경·도서관 소재를 특정 학생 후기나 제휴 학교의 증빙으로 표시하지 않는다. 도서관·건축물은 확인되지 않은 학교명·도시명으로 설명하지 않는다.

PC는 문구·상담 버튼과 사진을 나란히 배치한다. 모바일은 사진이 첫 화면에 먼저 보이고 문구·상담 버튼이 이어진다. 고정 하단 상담 버튼, 키보드 메뉴, 본문 바로가기도 유지한다. 기존의 상담·카카오톡·전화·약대·블로그 URL을 바꾸지 않는다.

## 확인한 파일·사진과 출처

변경 파일은 `index.html`, `assets/home.css`, `scripts/package_site.py`, `tests/check_home_browser.py` 및 `assets/home/`의 새 사진·출처 목록이다. 기존 `assets/home.js`, 홈 SSR·공개본 조회·CMS·발행 권한·DB 스키마는 변경하지 않는다.

| 파일 (`assets/home/`) | 실제 확인 내용·출처 | 용도·크기 |
|---|---|---|
| `london-1440.webp` | [Unsplash 원본 사진 CDN](https://images.unsplash.com/photo-1486299267070-83823f5448dd) · 웨스트민스터 다리, 엘리자베스 타워, 국회의사당 | 큰 화면 대응, 1440×960 · 274,562 B |

정상 TLS 요청으로 각 사진의 HTTP 200·크기·실제 장면을 확인했다. 본사 메인 `https://www.ukcentre.co.kr/`에서 건축물 사진의 현재 사용도 확인했다. 파일별 URL·바이트·크기·확인일은 `assets/home/photo-sources.json`에 보관한다. Unsplash의 일반 사진 이용 정책 링크는 [Unsplash License](https://unsplash.com/license)이며, **최신 라이선스 본문은 이 환경의 401 응답으로 재확인하지 못했다**. 확인하지 못한 촬영자나 개별 학교명은 만들어 기록하지 않는다.

사진은 로컬 파일로 제공해 방문자의 브라우저에서 외부 사진 CDN에 요청하지 않는다. 첫 사진은 `picture`·`srcset`·`sizes`·`fetchpriority=high`, 과정 사진은 크기 지정·지연 로딩을 사용한다. 모바일 390px·DPR 2에서도 작은 768px 사진을 선택하는 것을 확인했다. OG 공유 이미지도 실제 첫 화면 사진으로 맞췄다. 사무실을 나타내는 사업장 JSON-LD 사진은 실제 지점 사진을 유지한다.

## 완료 기준과 검증

가상의 로컬 CMS 계정·원고만 사용했으며 실제 원고 발행·상담 접수·Meta 이벤트는 전송하지 않았다. 2026-11-19 **25개 검증 그룹이 통과**했다.

| 실행 | 통과 | 확인 내용 |
|---|---:|---|
| `node tests/check_home.mjs` | 7 | 공개본만 초기 HTML에 표시, 초안·비공개·삭제 처리, 캐시·HEAD·정규 URL, DB 장애 시 정적 홈 |
| `python3 tests/check_home_browser.py` | 6 | 실제 사진 로딩·모바일 해상도 선택·외부 이미지 요청 없음, PC 1280×720/1366×768/1440×900 상담 버튼 첫 화면 노출, 320/360/390/430/768/1024px 가로 넘침 없음, 메뉴·사진·후기·JS 없는 최신 글·상담 이동 |
| `python3 scripts/check_meta_pixel.py` | 12 | 모의 라이브러리에서 기존 PageView·URL 제한·상담·차단 시 동작 유지 |

`git diff --check`, Python 구문 검사, 사진 5개의 실제 크기·출처 목록 일치, 공개 개발 폴더·ZIP 생성을 확인했다. 기존 약대 단일 파일 미리보기 해시는 변경되지 않았다. 모든 새 사진과 출처 목록은 공개 파일 허용 목록에 포함했다. CMS Functions나 라우트는 이 변경에서 수정하지 않았으며, 전날의 실제 Pages 라우터 검증을 오늘 새로 수행한 것으로 계산하지 않는다.

개발 성능은 로컬 Miniflare·새 Chromium 컨텍스트에서 **1.6Mbps·지연 150ms·CPU 4배 감속**, Meta 비활성 조건으로 PC 1366×768/DPR 1과 모바일 390×844/DPR 2를 각각 3회 측정했다. LCP 중앙값은 PC **1,000ms**, 모바일 **1,056ms**, 최초 화면 CLS는 6회 모두 **0**이었다. 두 화면 모두 82,540 B의 작은 사진을 선택했다. 입력 지연이나 실제 사용자 성능 측정은 아니다. 전날의 CPU·네트워크 무제한 측정값과 직접적인 전후 비교를 하지 않는다.

## 운영·복구

구현 커밋은 [`884fb99`](https://github.com/uksinchon/uksinchon-site/commit/884fb99) · **R07/R06**이다. 정적 홈·사진·패키징과 해당 화면 검증을 하나의 독립적인 UI 커밋으로 묶었다. 위 25개 검증 그룹과 사진·성능 관찰이 이 커밋의 동작을 확인한다. 검증·사진 출처 기록은 별도 문서 커밋으로 연결한다. 최종 커밋의 Cloudflare Pages 체크가 성공한 뒤 배포 완료로 보고한다.

URL·게시글 ID·slug·DB·공개 스냅샷·직원 입력·이미지 업로드 방식·원고 발행 규칙은 변경하지 않아 데이터 변환이 필요하지 않다. 복구는 화면 커밋을 되돌려 재배포하면 된다. 새 사진 파일은 이전 코드에서 참조되지 않는다. 기존 초안이나 글 이력을 일괄 수정하지 않는다. 미추적 `docs/content-strategy/`는 커밋에 추가하지 않는다.

실제 사용자 성능·상담 전환·Search Console·CDN 차단 설정은 별도의 운영 확인 대상이다. 로컬 성능 관찰은 필드 Core Web Vitals나 검색·AI 노출 성과의 보장이 아니다.
