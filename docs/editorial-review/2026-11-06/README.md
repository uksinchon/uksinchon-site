## CMS 적용과 공개

검토 완료 데이터는 [reviewed-pilots-data.js](../../../cms/server/reviewed-pilots-data.js)에 한정해 배포한다. 해당 파일은 임의 클라이언트 입력을 승인하는 양식이 아니라 이번에 실제 작성·대조한 다섯 원고의 서버 기준본이다.

1. 관리자 `/admin/` → **네이버 가져오기 → 먼저 검토할 대표 글 5개 → Codex 검토 완료 원고 5개 적용**. 새 항목만 비공개 초안으로 만든다. 외부 유료 AI 호출은 없다.
2. 이미 초안이 있는 항목은 자동으로 덮어쓰지 않는다. 글을 연 뒤 **이 글에 Codex 검토 원고 적용**을 선택하면 기존 버전·공개본·URL을 남기고 새 초안 버전을 만든다.
3. **사람이 다시 사실 확인란을 체크할 필요는 없다.** 현재 원고·원문·검토 기한이 서버 기준본과 일치하면 AI 검토 기록으로 공개 조건을 충족한다. 별도의 공개 승인 버튼은 실제 발행 동작이다.
4. 적용과 공개 시 네이버 원문을 정상 경로로 다시 읽는다. 원문 변경·읽기 실패·원고 수정·기한 경과·다른 글에는 완료 증명을 적용하지 않는다. AI 검토자와 공개를 실행한 관리자 계정은 서로 다른 책임으로 기록한다.

이 환경에는 운영 CMS 세션·D1 인증이 없으므로 **실제 운영 DB에 초안을 넣거나 글을 공개한 것은 아니다**. 완료된 내용 검토와 관리자 화면의 배포를 실제 글 공개와 구분한다. Secret·로그인 우회·익명 DB 쓰기 기능을 추가하지 않았다. 공개 원고 확대와 향후 새 글의 자동 검토는 별도 단계다.

기존 DB의 변환·테이블 변경은 없다. 적용은 새 snapshot 버전이며, 이전 버전을 복구하더라도 내용 검토는 그 현재 버전과 원문에 다시 맞아야 한다. 아직 쓰지 않은 기능은 코드 커밋을 되돌릴 수 있다. 사용한 뒤에는 기존 AI 검토 메타를 읽는 호환 코드를 유지하고 잘못 공개한 글은 기존 ‘공개 내리기’로 회수한다. 검토 원고 재적용은 자동 복구가 아니라 명시적인 새 버전 저장이다.
