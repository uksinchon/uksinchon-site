영국유학센터 신촌점직원 글쓰기 사용 안내

질문 하나부터, 글을 쌓아 주세요.

작성: uksinchon.com/admin/ · 공개 글: uksinchon.com/blog/

  1. 계정을 받아 로그인합니다.

    직원은 첫 로그인 때 임시 비밀번호를 바꿉니다. ‘새 글 쓰기’에서 제목과 본문을 작성합니다.

  2. 글 유형과 카테고리를 고릅니다.

    소식·일상, 지원 조건·준비 안내, 비교·비용, 상담 사례·후기 중 글의 목적에 맞는 유형을 고릅니다. 모든 글에 같은 표나 FAQ를 넣을 필요는 없습니다.

  3. 필요한 사진과 표를 넣습니다.

    사진은 JPG·PNG·WebP를 올리면 긴 쪽 1600px 이내로 줄여 저장합니다. 본문에 커서를 놓고 도구 모음의 이미지 버튼을 눌러 파일을 고르면 바로 삽입됩니다. 사진을 클릭하고 네 모서리의 파란 조절점을 마우스로 끌면 비율을 유지하며 크기가 바뀝니다. ‘원래 크기’로 되돌릴 수 있고, 왼쪽·가운데·오른쪽 정렬 버튼도 사용할 수 있습니다. 설명·출처·대표 사진은 ‘사진 설명·출처 · 선택’을 열어 필요할 때만 추가합니다. YouTube 링크는 그대로 붙여넣거나 한 줄에 입력 후 Enter를 누르면 영상으로 삽입됩니다. 도구 모음의 ▶ 버튼에서도 영상 주소를 넣을 수 있습니다. 상단 도구 모음의 표 아이콘을 누르고 격자에서 원하는 열·행 수를 고르면 커서 위치에 표가 들어갑니다. 각 칸을 클릭해 바로 입력하고, 표 아래의 행·열 추가/삭제 버튼으로 크기를 바꿉니다. 기존 비교 표는 ‘표 수정’ 버튼으로 수정할 수 있습니다.

  4. 이 글에 필요한 근거를 정리합니다.

    입학·학비·장학금·비자·자격 안내에는 적용 학년도·기간·대상, 학교·기관의 공식 자료, 실제 확인일과 대조 범위를 적습니다. 소식·사례에 해당하지 않는 조건은 억지로 채우지 않습니다. 개인정보와 공개할 수 없는 자료를 본문에 넣지 않습니다.

  5. ‘저장 완료’를 확인하고 미리보기로 읽습니다.

    잠시 멈추면 공동 DB에 자동 저장합니다. 화면을 닫기 전 ‘초안 저장’을 눌러 완료 표시를 확인하세요. 저장 실패 시 화면을 닫지 말고 ‘수정 이력·원고 보관’에서 현재 원고를 파일로 보관합니다. 미리보기는 작성자와 관리자만 볼 수 있습니다.

  6. ‘검토 요청하기’를 누릅니다.

    관리자가 확인하고 공개 승인합니다. 요청은 글 목록에 표시되며 별도 메일·메신저 알림은 보내지 않습니다.

네이버 사진을 함께 가져올 때

네이버 초안의 네이버 사진 함께 가져오기에서 사진을 미리보고 최대 12개씩 고릅니다. 사진을 내려받아 WebP로 변환하고 커서 위치부터 원문 순서로 추가·저장합니다. 네이버에 저장된 JPG·PNG·WebP 정지 사진을 지원합니다.

출처·크기는 자동 기록합니다. 사진별 설명과 사용 근거는 편집할 수 있고, 중간에 실패하면 성공한 사진은 유지하며 실패 이유를 표시합니다. 사진을 추가해도 기존 공개본이 바로 바뀌지는 않습니다. 네이버 가져오기 사용 안내

글 삭제와 휴지통 복구

관리자는 전체 글 목록의 각 글에서 삭제를 누를 수 있습니다. 확인 창에서 제목과 공개 중인 글의 처리 내용을 확인합니다. 삭제하면 일반 목록과 공개 사이트에서 내려가며, 원고·사진·수정 이력은 휴지통에 보관합니다.

목록 상단의 휴지통에서 제목으로 찾고 복구를 누르면 원래 주소의 비공개 초안으로 돌아옵니다. 자동으로 다시 공개하지 않습니다. 필요한 현재 버전 검토와 별도의 공개 승인을 거쳐 게시합니다. 직원 계정에는 삭제·복구 버튼이 보이지 않습니다.

네이버에서 가져온 글도 먼저 휴지통에서 복구해야 재편집할 수 있습니다. 네이버 원문은 지우지 않습니다. 통신 실패나 다른 창의 수정으로 삭제가 실패하면 안내를 확인하고 목록을 다시 불러옵니다.

최초 발행·내용 수정·사실 확인 날짜는 다릅니다.

  • 최초 발행일: 이 사이트에서 처음 공개한 날짜입니다. 네이버 원문 발행일과 별개입니다.
  • 내용 수정일: 판단에 영향을 주는 조건이나 내용을 바꾸어 공개한 날짜입니다. 단순 저장과 재승인만으로 바뀌지 않습니다.
  • 사실 확인일: 실제 자료를 다시 읽고 대조한 날짜입니다. 내용을 바꾸지 않고 확인만 했다면 이 날짜만 새로 기록할 수 있습니다.

공개 글을 고칠 때에는 수정의 성격과 이유를 적어 주세요. 오탈자·서식 수정은 해당 항목을 선택합니다. 제목과 카테고리를 바꾸어도 글 주소는 유지됩니다. 관리자 승인 전에는 기존 공개본이 계속 보입니다.

관리자의 검토와 공개 승인

  1. 검토 요청 글을 열어 출처·대상·예외·날짜·사진과 표를 실제로 대조합니다.
  2. 지원 조건·비교 글은 ‘공개 전 사실 확인’의 세 항목을 확인하고 현재 버전의 사실 확인을 기록합니다. 사진 설명과 사용 근거는 선택 입력입니다. 사용할 수 있는 사진인지 확인해 주세요.
  3. 네이버 글은 위쪽 ‘네이버 원문 대조’도 확인합니다. 세 항목을 체크하고 ‘현재 버전 검수 완료 기록’을 누르면, 조건 안내·비교 글의 공식 자료 사실 확인도 함께 기록합니다. 필요한 날짜와 공식 자료를 먼저 채워 주세요.
  4. 별도로 ‘이 버전 공개 승인’을 눌러 게시합니다. ‘현재 공개본 보기’에서 실제 주소와 모바일 화면을 확인합니다.

검수 뒤 원고를 고치면 새 버전을 다시 확인해야 합니다. ‘공개 내리기’는 글과 해당 공개 사진을 내리며 원고·수정 이력은 보존합니다. 사진 파일이나 외부 서비스에 이미 복제된 정보까지 회수하는 기능은 아닙니다.

Codex가 검토한 대표 글 5개 사용하기

관리자로 로그인해 네이버 가져오기 → 먼저 검토할 대표 글 5개 → Codex 검토 완료 원고 5개 적용을 누릅니다. Codex가 원문·공식 자료·약관을 대조해 재작성한 원고이며, 미확인 수치와 사용 권리를 확인하지 못한 사진은 제외했습니다.

이미 있는 원고는 자동으로 덮어쓰지 않습니다. 해당 글을 열고 이 글에 Codex 검토 원고 적용을 선택하면 이전 버전과 공개본을 남기고 새 초안으로 적용합니다. 이 원고는 사람이 사실 확인란을 다시 체크할 필요 없이 별도로 ‘이 버전 공개 승인’을 누를 수 있습니다.

검토자는 ‘Codex (AI 검토)’로 기록합니다. 내용·원문이 바뀌거나 재확인 시점이 지나면 이전 검토를 사용할 수 없습니다. 이 다섯 원고 외의 새 글을 자동 승인하는 기능은 아닙니다. ‘원문 정리 초안만 준비’는 검토 완료본과 다른 선택입니다. 네이버 연결 안내

원고를 보관하고 복구할 때

‘수정 이력·원고 보관’에서 이전 저장본을 새 버전으로 불러올 수 있습니다. JSON 보관 파일에는 본문·표·사진 설명·출처 등 원고 설정이 포함됩니다. 같은 글에서 ‘보관한 원고 불러오기’로 복구합니다. 사진 파일과 DB 전체 백업은 포함하지 않습니다.

오래된 보관본에 없던 출처·사진 설명은 복구 후 다시 확인합니다. 실제 운영 DB의 전체 백업·복구는 관리자 Cloudflare 환경에서 별도로 관리합니다.

아직 공동 저장소 연결 안내가 나온다면

관리자가 Cloudflare의 D1을 Pages 프로젝트의 CMS_DB에 연결하고 초기 설정키 CMS_SETUP_TOKEN을 암호화된 환경 변수로 설정해야 합니다. 최신 배포 후 첫 관리자 계정을 만들면 직원 계정을 추가할 수 있습니다.

비밀번호·설정키는 채팅·글·공개 저장소에 올리지 마세요. 초기 설정키를 잃어버렸다면 첫 관리자 화면의 새 키 만들기 안내를 따릅니다.

운영 범위

댓글·예약 발행·PDF/영상 업로드·직원 간 실시간 공동 편집·이메일 알림은 연결하지 않았습니다. 사진은 현재 공동 DB에 저장합니다. 원고 저장, 사람 검수, 실제 공개와 검색 노출은 각각 구분합니다.
