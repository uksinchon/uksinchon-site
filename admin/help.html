영국유학센터 신촌점직원 글쓰기 사용 안내

첫 글은 이렇게 올려 주세요.

작성 주소: uksinchon.com/admin/ · 공개된 글: uksinchon.com/blog/

  1. 관리자에게 계정을 받습니다.

    이메일과 임시 비밀번호로 로그인합니다. 첫 로그인에서는 새 비밀번호를 정합니다.

  2. ‘새 글 쓰기’를 누릅니다.

    제목을 쓰고 아래 큰 칸에 본문을 적습니다. 학생이 실제로 궁금해한 질문, 답변과 중요한 조건부터 시작하세요.

  3. 필요한 서식과 사진을 넣습니다.

    소제목·굵게·목록·인용·링크를 쓸 수 있습니다. ‘사진 추가’로 JPG·PNG·WebP를 올립니다. 사진은 긴 쪽 1600px로 줄여 저장합니다. 설명은 사진 아래 문단에 적어 주세요.

  4. 카테고리와 필요한 근거를 정리합니다.

    요약은 선택입니다. 비워두면 본문 첫 부분을 사용합니다. 가격·입학 조건·정책 등에는 공식 자료 주소와 정보 확인일을 적어 주세요. 학생 개인정보와 내부 전용 자료를 공개 원고에 넣지 않습니다.

  5. ‘저장 완료’를 확인합니다.

    글을 쓰다 잠시 멈추면 공동 DB에 자동 저장합니다. 화면을 닫기 전 ‘초안 저장’을 누르고 완료 표시를 확인하세요. 인터넷이 끊겨 ‘저장 실패’가 보이면 화면을 닫기 전에 현재 원고를 파일로 보관할 수 있습니다.

  6. ‘저장 후 미리보기’로 읽어봅니다.

    미리보기는 로그인한 작성자와 관리자만 볼 수 있습니다. 오탈자·가격 적용 조건·출처와 사진을 확인합니다.

  7. ‘검토 요청하기’를 누릅니다.

    관리자가 글을 확인하고 공개 승인합니다. 검토 요청은 글 목록에 표시되며 별도 메일·메신저 알림을 보내지는 않습니다.

공개한 글을 수정할 때

같은 글을 다시 열어 수정·저장하고 검토를 요청하세요. 관리자 승인 전에는 기존 공개본이 유지됩니다. 글 주소도 유지됩니다.

‘수정 이력·원고 보관’에서 이전 저장본을 불러와 새 버전으로 저장할 수 있습니다. ‘현재 원고 파일로 보관’은 본문을 JSON 파일로 내려받으며, 같은 글에서 ‘보관한 원고 불러오기’로 복구할 수 있습니다. 사진 파일과 DB 전체 백업은 포함하지 않습니다.

관리자의 공개 승인

  1. 글 목록에서 ‘검토 요청’을 선택하고 검색합니다.
  2. 글과 사진·출처·적용 조건을 확인합니다.
  3. ‘이 버전 공개 승인’을 누르고 확인합니다.
  4. ‘현재 공개본 보기’로 실제 공개 주소를 확인합니다.

‘공개 내리기’를 누르면 독자에게 글이 보이지 않으며, 원고와 수정 이력은 보관됩니다. 직원 계정 메뉴에서는 계정 추가·사용 중지·임시 비밀번호 재설정이 가능합니다.

아직 ‘공동 저장소 연결’ 안내가 나온다면

현재 사이트는 작성 화면 배포와 공동 DB 연결이 분리되어 있습니다. 먼저 관리자가 Cloudflare에서 D1 데이터베이스를 만든 뒤 Pages 프로젝트의 CMS_DB에 연결하고, 초기 설정키 CMS_SETUP_TOKEN을 암호화된 환경 변수로 연결해야 합니다. 재배포 후 첫 관리자 계정을 만들면 직원 계정을 추가할 수 있습니다.

비밀번호나 설정키를 채팅·글·공개 저장소에 올리지 마세요. DB 연결 전에는 로그인·공동 저장·발행이 작동하지 않습니다.

초기 버전의 범위

예약 발행·댓글·PDF/영상 업로드·직원 간 동시 공동 편집·이메일 알림·자동 비밀번호 찾기는 연결하지 않았습니다. 사진은 초기 운영을 위해 D1에 저장하며 대량 미디어 운영 시 별도 저장소로 확장합니다. 사진을 넣을 권한과 공개할 정보의 정확성은 발행 전에 확인합니다.
