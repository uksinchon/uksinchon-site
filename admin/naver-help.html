영국유학센터 신촌점네이버 글 가져오기

이미 Codex 검토를 마친 대표 5개

네이버 가져오기에서 ‘Codex 검토 완료 원고 5개 적용’을 누르면 완료 원고를 비공개 초안으로 적용합니다. 기존 글은 자동으로 덮어쓰지 않으며, 글을 열어 ‘이 글에 Codex 검토 원고 적용’으로 새 버전을 만들 수 있습니다. 사람의 사실 확인란을 다시 체크할 필요는 없습니다. 공개 승인은 별도입니다.

AI 검토와 사람 검토를 구분해 기록하며, 현재 원고·원문·검토 기한이 일치할 때만 유효합니다. 아래는 그 외 일반 글의 준비 과정입니다.

네이버 글을 검토 가능한 신촌점 초안으로

대상은 pedu2 블로그입니다. 원문을 읽고 신촌점 독자를 위한 초안으로 준비합니다. 자동으로 공개하지 않습니다.

  1. 관리자로 로그인하고 네이버 가져오기를 엽니다.
  2. ‘새 글 감지 허용’을 켜고 저장한 뒤 ‘지금 새 글 확인’을 누릅니다. 첫 확인은 현재 RSS의 기존 글을 기준 목록으로만 등록합니다.
  3. 글의 ‘원문 보기·보완’에서 전체 본문을 읽습니다. 자동으로 읽지 못하면 네이버에서 원문 텍스트를 직접 붙여넣고 확인해 저장할 수 있습니다.
  4. AI가 연결되어 있으면 ‘AI 재편집 초안 만들기’를 누릅니다. 연결 전에는 ‘원문 정리 초안 만들기 · AI 없이’를 사용해 직접 재편집할 수 있습니다.
  5. 원문·초안을 대조하고 내용과 사진·출처·조건을 수정합니다. 세 가지 확인란을 체크한 뒤 ‘현재 버전 검수 완료 기록’을 누릅니다.
  6. 별도로 ‘이 버전 공개 승인’을 눌러야 사이트에 게시됩니다. 검수 이후 수정하거나 원문이 변경되면 다시 검수해야 합니다.

초안 작성과 관리자 검수는 같은 로그인 계정으로 할 수도 있습니다. 원문 정리 초안은 AI가 편집한 글이 아니므로 직접 구조와 문장을 보완해 주세요.

어디까지 읽었는지 확인해 주세요

네이버 RSS는 글의 앞부분만 담을 수 있습니다. 새 글 발견에 사용하고 본문은 별도로 읽습니다. 공개 본문 영역을 찾지 못한 글은 ‘원문 보완 필요’로 남습니다.

사진은 자동 복사하거나 OCR하지 않습니다. 사진 참조 개수와 누락 범위를 검토 화면에 표시합니다. 사진 속 표·금액·입학 조건은 사람이 확인하고 사용 가능한 사진만 ‘사진 추가’로 등록해 주세요.

AI는 원문의 근거 문구와 금액·날짜·수치의 일부 형식을 대조하지만 모든 사실을 검증하는 도구는 아닙니다. 네이버 글이 학교 공식 자료를 대체하지 않습니다. 과거 프로모션과 학비의 현재 적용 여부는 공식 근거로 다시 확인합니다.

자동 재편집 연결

Cloudflare의 기존 Pages 프로젝트 uksinchon 운영 환경에 다음을 설정합니다.

  • Secret OPENAI_API_KEY: 운영자가 관리하는 OpenAI API 키
  • 일반 변수 CMS_REWRITE_MODEL: 해당 API 계정에서 사용 가능한 모델 ID

설정 저장 후 최신 배포를 다시 실행합니다. 값이 존재하는 것과 실제 호출 성공은 다릅니다. 한 글로 결과를 확인한 뒤 운영하세요.

공개 네이버 원문 텍스트·제목·주소·원문 게시일을 OpenAI API에 전달하며 store:false로 요청합니다. API 제공자의 실제 보관 정책은 별도 정책을 따릅니다. API 이용료는 ChatGPT 구독과 별도로 발생할 수 있고, 모델·입출력 길이에 따라 달라집니다. 연결 전 운영자가 공식 요금과 한도를 확인합니다.

모델은 외부 링크를 탐색하거나 가격을 다시 계산하지 않습니다. 원문에 없는 수치나 대조할 수 없는 근거가 나오면 초안 생성을 보류합니다. 보류된 글을 자동으로 계속 재요청하지 않으며, 관리자가 내용을 확인한 뒤 다시 실행합니다.

매시간 새 글 확인 연결

Cloudflare Pages 자체에는 이 작업의 예약 실행을 설치하지 않았습니다. 별도 Worker uksinchon-naver-sync를 만들고 아래 코드를 사용합니다.

예약 Worker 코드 받기

  1. 네이버 가져오기 화면에서 ‘예약 감지용 키 만들기’를 누르고 키를 별도로 보관합니다. 초기 관리자 설정키와는 다른 키입니다.
  2. 기존 Pages와 새 Worker 양쪽에 동일한 Secret CMS_NAVER_CRON_TOKEN을 저장합니다. 키를 코드나 채팅에 넣지 않습니다.
  3. Worker의 예약 트리거를 0 * * * *로 설정합니다. 매시간 실행하며 Cloudflare 예약 기준은 UTC입니다.
  4. Pages 설정 변경 후 재배포하고 Worker도 배포합니다. 관리 화면의 ‘예약 호출’ 시각과 작업 결과를 확인합니다.

매번 RSS를 확인하고 대기 중인 새 글을 최대 2개까지 처리합니다. 과거 글 전체를 스캔하지 않으며 RSS 범위를 벗어나기 전에 발견하지 못한 글은 개별 주소로 추가해야 합니다. AI 설정이 없으면 원문을 확보한 뒤 AI 연결 대기로 남깁니다.

Worker는 초안 수집 요청만 할 수 있고 공개 승인 기능을 호출하지 않습니다. 연결 정보를 입력하기 전에는 정기 감지가 작동한다고 표시하지 않습니다. 알림 메일·메신저 연동은 포함하지 않았으므로 관리자 화면에서 대기 글을 확인해 주세요.

원문 수정과 중복 처리

같은 네이버 글번호는 한 항목으로 관리합니다. 재확인·재실행으로 같은 글이 중복 생성되지 않도록 잠금과 DB 고유 키를 사용합니다. 네이버 원문이 바뀌면 검수 기록을 무효화하고 기존 초안·공개본은 그대로 둡니다. 관리자가 변경 내용을 확인해 새 버전으로 재편집·검수·공개합니다.

원문이 수정되어도 RSS 내용이 바뀌지 않으면 즉시 감지하지 못할 수 있습니다. 검수 기록 시 자동 추출 글의 본문을 다시 읽으며, 최신 원문 확인이 실패하면 검수를 기록하지 않습니다. 수동 입력 원문은 담당자의 전체 원문 대조 확인을 사용합니다.

검색·AI 인용은 보장되지 않습니다. 네이버와 사이트는 같은 글을 그대로 복제하기보다 질문·조건·근거와 독자에게 필요한 안내를 중심으로 편집하고, 바탕이 된 네이버 주소를 출처로 유지합니다.
