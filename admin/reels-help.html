블로그 한 편으로 45초 쇼릴 만들기

  1. 쇼릴 만들기 — 「새 블로그 글」에서 고르거나 네이버 글 주소를 넣습니다.
  2. AI 기획안 만들기 — 장면 구성·화면 문구·내레이션 원고·채널별 문구가 한 번에 만들어집니다(1~2분). 노란 상자 「확인이 필요한 내용」의 수치·조건은 반드시 원문과 대조합니다.
  3. 장면 검토 — 장면마다 사진(블로그 사진 중 선택)과 문구를 고칩니다. *별표*로 감싼 말은 강조색, 줄바꿈은 그대로 화면 줄바꿈이 됩니다. 순위표·표는 한 줄에 한 행, |로 칸을 나누고 마지막 칸에 *를 넣으면 강조 행입니다.
  4. 내레이션 — 한 줄이 한 장면입니다. 줄 수를 장면 수와 맞춥니다. 숫자는 숫자로, 영어는 영어로(4, 5등급 · QS · IELTS 5.0). 타입캐스트에서 원고 전체를 한 파일로 만들어 mp3 올리기로 올립니다. 음성 없이 음악만으로도 만들 수 있습니다.
  5. 채널별 문구 — 유튜브·인스타·틱톡·스레드·네이버 클립·카카오 소식 문구를 고칩니다. 글자 수가 한도를 넘으면 빨간색으로 표시됩니다.
  6. 배경음악 — 목록에서 고릅니다. 새 곡은 Pixabay 곡 페이지에 방패(Content ID Registered) 표시가 없는 것을 확인한 뒤에만 추가합니다. 방패가 있는 곡은 유튜브에서 재생이 막힐 수 있습니다.
  7. 저장하고 영상 만들기 — GitHub 렌더 서버가 5~10분 동안 영상(음악 박자에 맞춘 장면 전환, -14 LUFS)과 썸네일을 만듭니다. 화면을 닫아도 됩니다.
  8. 영상 확인 후 승인 — 영상·썸네일을 끝까지 확인하고 시간(최적 시간·바로·지정)을 골라 승인합니다. Claude가 1시간 안에 유튜브·인스타·틱톡·스레드에 예약하고 결과를 이 화면에 기록합니다. 네이버 클립·카카오톡 소식은 문구를 복사해 직접 올립니다.

되돌리기·건너뛰기

승인 후 고칠 곳이 생기면 관리자가 수정으로 되돌리기를 누릅니다(아직 예약 전이면 대기열에서 빠집니다). 이미 예약된 게시물은 Metricool에서 직접 고치거나 Claude에게 요청합니다. 쇼릴로 만들지 않을 글은 건너뛰기를 누릅니다.
