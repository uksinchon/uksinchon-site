첫 관리자 연결

함께 쓸 글쓰기 공간을 연결해 주세요.

직원이 쓴 글과 사진은 공동 DB에 저장합니다. 아래 연결을 완료해야 로그인·글 저장·공개를 사용할 수 있습니다.

  1. Cloudflare에서 D1 데이터베이스 만들기

    이름 예시: uksinchon-cms. 기존 uksinchon Pages 프로젝트에 D1 바인딩 CMS_DB로 연결합니다.

  2. 첫 관리자 설정키 연결하기

    아래에서 만든 키를 Pages의 암호화된 환경 변수 CMS_SETUP_TOKEN에 저장합니다. 키는 채팅이나 글에 올리지 마세요.

  3. 최신 배포를 다시 실행하고 관리자 만들기

    설정 저장 후 최신 코드로 재배포합니다. 이 화면을 새로고침하면 첫 관리자 계정을 만들 수 있습니다.

설정키를 잃어버렸나요?

Cloudflare의 Secret은 원래 값을 다시 볼 수 없습니다. 새 키를 만들어 Cloudflare 값도 교체해 주세요.

  1. 새 키를 복사하거나 파일로 보관합니다.
  2. Cloudflare의 CMS_SETUP_TOKEN Secret 값을 새 키로 교체하고 저장합니다.
  3. 최신 Production 배포를 다시 실행합니다.
  4. 완료되면 이 화면에서 관리자 정보를 입력하고 등록합니다. 초기 설정키 칸에는 새 키가 이미 들어 있습니다.

이 탭을 닫거나 새로고침하지 마세요. 새 키 생성만으로 Cloudflare 설정이 바뀌지는 않습니다.
